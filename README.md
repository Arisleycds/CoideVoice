# DeepEdit

Editor assistido por IA para projetos em `C:\deepedit\{projeto}`.

## Uso

```bash
npm install
npm run dev
```

## Fluxo

1. Abra o app -> painel **Projetos** lista pastas em `C:\deepedit`.
2. Clique em **Abrir** num projeto (ou **Novo Projeto**).
3. Clique em **Chat de Edicao (oculto)** para iniciar o agente.
4. Clique em **Chat Principal** para conversar.
5. Tool calls aparecem em **Operacoes Pendentes**.
6. Clique **Executar** ou ative **Auto-executar**.
7. Se falhar, o chat principal recebe o erro (fallback).
